工具箱+ Claude Code+ Codex

0 课前准备

二十分钟后，你有一个 Agent 能读能写的项目文件夹，并且已经让它干完第一件活。

需要什么

一台 Mac 或 Windows 电脑，加上至少一个订阅：Claude 的 Pro 或以上，或者含 Codex 的 ChatGPT 套餐。两个都有最好。

不需要会编程，也不需要先学命令行。下面全程用桌面应用，像用聊天软件一样用。

1 装 Claude 桌面版，5 分钟

从 Claude Code 桌面版说明 页面下载安装包，安装后用你的 Claude 账号登录，点窗口上方的 Code 标签。Code 标签里的 Claude 能读写你电脑上的文件，这是它和网页聊天最大的区别。

2 打开练习文件夹，3 分钟

下载第 0 课练习材料

解压到桌面，得到 lesson-0 文件夹，里面只有一份乱糟糟的会议记录 notes.md。

在 Code 标签的输入框附近有几个选项：运行位置选 Local，项目文件夹选刚解压的 lesson-0，权限模式先选最保守的 Manual。Manual 下它每次改文件或运行命令都会先问你，你能看清它每一步在做什么。

3 让它干第一件活，5 分钟

把下面这段复制进输入框：

读 notes.md，这是一次组会的记录。
把它整理成一页纪要：列出做了哪些决定，每个人的待办是什么，截止时间是哪天。
存成 minutes.md。做完告诉我新建或改动了哪些文件。

它会先读文件，再问你能不能新建 minutes.md，同意即可。打开文件夹，minutes.md 出现了，打开看内容对不对。

接着追加一句，练习多轮对话：

把待办按截止日期从近到远排好，再另存一份英文版 minutes-en.md。

这张任务卡的写法后面每堂课都会用：读什么，做什么，存到哪，做到哪里停。四件事说清楚，Agent 就很少跑偏。

4 装 Codex，5 分钟

按 Codex 快速入门 下载 Codex 桌面应用，用 ChatGPT 账号登录，打开同一个 lesson-0 文件夹，发这段：

读 notes.md 和 minutes.md。检查纪要有没有漏掉或写错会上的决定，列出来。不要改任何文件。

一家写，另一家查。这是第 1 课的核心做法，这里先尝一口。

5 可选：命令行

习惯终端的人可以装命令行版，功能和桌面版一样。Claude Code 在 Mac 上运行 curl -fsSL https://claude.ai/install.sh | bash，Codex 运行 npm i -g @openai/codex。之后在项目文件夹里输入 claude 或 codex 即可开始。

最容易出错的地方

一个对话聊到底。 Agent 每回答一次，都要把这个对话里之前的全部内容重读一遍。聊得越久越慢、越贵，也越容易忘掉早先交代的要求。换一件事就开新对话；需要接着用的东西，让它写进文件。

把整个桌面设成项目文件夹。 Agent 会到处翻找，又慢，也可能动到不该动的文件。一件任务一个文件夹，要用的材料放进去。

两个对话同时改同一个文件。 后保存的会覆盖先保存的，而且两边都以为自己做完了。同一件事只交给一个对话。

订阅和 API Key 混着用。 如果电脑里设过 ANTHROPIC_API_KEY，Claude Code 第一次启动会问你要不要用它，同意就改成按用量计费。用订阅就选不用。

要点

  • Agent 只认文件夹里的东西：材料放进去，结果存成文件。
  • 一件事，一个对话，一个文件夹。
  • 任务卡写清四件事：读什么，做什么，存到哪，做到哪里停。
Toolbox+ Claude Code+ Codex

0 Setup

In twenty minutes you will have a project folder an agent can read and write, and it will have finished its first job.

What you need

A Mac or Windows computer and at least one subscription: Claude Pro or above, or a ChatGPT plan that includes Codex. Both is best.

You do not need to code or learn the command line first. Everything below uses the desktop apps, much like a chat app.

1 Install the Claude desktop app, 5 minutes

Download the installer from the Claude Code desktop page, sign in with your Claude account, and click the Code tab at the top. In the Code tab, Claude can read and write files on your computer. That is the big difference from chatting on the web.

2 Open the exercise folder, 3 minutes

Download the Session 0 materials

Unzip it to your desktop. You get a lesson-0 folder holding one messy set of meeting notes, notes.md.

Near the input box in the Code tab there are a few options. Set the environment to Local, choose the lesson-0 folder as the project folder, and start with the most cautious permission mode, Manual. In Manual mode it asks before every file edit or command, so you can see each step it takes.

3 Give it its first job, 5 minutes

Paste this into the input box:

Read notes.md, the notes from a group meeting.
Turn them into one page of minutes: what was decided, each person's to-dos, and their deadlines.
Save it as minutes.md. When you're done, tell me which files you created or changed.

It reads the file first, then asks whether it may create minutes.md. Say yes. Open the folder: minutes.md is there. Check whether the content is right.

Then send one more line to practise a multi-turn conversation:

Sort the to-dos by deadline, soonest first, and save a Chinese version as minutes-zh.md.

Every session uses this way of writing a task card: what to read, what to do, where to save it, where to stop. Say those four things and the agent rarely drifts.

4 Install Codex, 5 minutes

Follow the Codex quickstart to install the Codex desktop app, sign in with your ChatGPT account, open the same lesson-0 folder, and send:

Read notes.md and minutes.md. Check whether the minutes miss or misstate any decision from the meeting, and list them. Don't change any files.

One vendor writes, the other checks. That is the core habit of session one, and you just had a first taste.

5 Optional: the command line

If you like the terminal, install the command-line versions. They do the same things as the desktop apps. For Claude Code on a Mac, run curl -fsSL https://claude.ai/install.sh | bash; for Codex, run npm i -g @openai/codex. Then type claude or codex inside a project folder to start.

Where agents go wrong most

One conversation for everything. Every time the agent replies, it rereads the whole conversation so far. The longer you chat, the slower and more expensive it gets, and the more likely it forgets what you asked early on. Start a new conversation for each new task, and have the agent write anything you need later into a file.

Making your whole desktop the project folder. The agent searches everywhere, which is slow and may touch files it shouldn’t. One task, one folder, with the material it needs inside.

Two conversations editing the same file. The later save overwrites the earlier one, and both think they finished. Give each task to one conversation only.

Mixing a subscription with an API key. If ANTHROPIC_API_KEY is set on your machine, Claude Code asks on first launch whether to use it. Saying yes switches you to pay-per-use billing. If you’re on a subscription, say no.

Key points

  • The agent only knows what is in the folder: put material in, save results as files.
  • One task, one conversation, one folder.
  • A task card says four things: what to read, what to do, where to save it, where to stop.
