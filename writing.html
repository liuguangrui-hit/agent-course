1 Agent 写作

一小时后，你手里有一段被重讲过的稿子，读起来像你最欣赏的那篇论文，看不出 AI 写过；还有一个以后随时能调用的写作 Skill。

下载第 1 课练习材料

先看成品，5 分钟

打开练习材料里的 before.md 和 after.md。两份说的是同一件事：一个 Agent 三个月替课题组初筛新论文。前一份是常见的 AI 稿，开头铺背景，满篇在一定程度上和值得注意的是，结尾一句不是取代而是助手。后一份第一句就是结果：

三个月里，一个 Agent 替我们组读完了 4200 篇新论文。它只推荐了 310 篇，其中 268 篇确实值得精读。

数字一个没变，变的是讲法。这堂课就做这件事。

为什么会有 AI 味，10 分钟

AI 味主要来自三种习惯。一是限定堆满，每句都带着可能或者在一定程度上，给自己留后路。二是套话句式，不是什么而是什么，这正是，总之。三是什么都罗列，不做取舍，读者找不到重点。

让 Agent 一句一句地润色，这三样只会越改越多：每一轮它都在原句上加补充，稿子越来越长。管用的办法是给它一篇范文，让它读懂原稿后合上原稿，围绕最抓人的一点另起一稿重讲。

还有一点：自己写的东西自己审不出毛病，模型也一样。同一个模型写和审，品味相同，问题互相看不见。所以这堂课让 Claude 写，让 Codex 审。

练习 1：一句话润色，10 分钟

先做一个对照组。在 Claude 里打开 lesson-1 文件夹，发：

读 draft.md，把它改得更好读，存成 v1.md。

拿 style_table.md 对一遍 v1。多半会发现：词换了，句子顺了，开头还在铺背景，限定还在。

练习 2：照范文重讲，15 分钟

范文用一篇写得好的论文。课上用 ResNet 那篇，它的摘要五句话讲完一件事；课后换成你自己最欣赏的那篇。

把 arXiv 1512.03385 的 PDF 下载到 exemplar/ 文件夹。
读这篇范文的摘要和引言，用三句话告诉我它的开头是怎样抓住读者的。
然后读 draft.md，告诉我其中最值得读者记住的一点是什么。
不要在原稿上改。围绕这一点，照范文的讲法另起一稿，存成 v2.md。

把 v1 和 v2 放在一起看。v2 应该第一句就是结果，而且明显更短。

练习 3：把要求留下来，请另一家来审，15 分钟

写进 AGENTS.md。 刚才你可能已经说了好几遍去掉背景铺垫、不要堆限定。每次开新对话都重说一遍太累，把它写进项目里的 AGENTS.md，Codex 每次开工都会先读它。练习材料里的 CLAUDE.md 只有一行 @AGENTS.md，意思是让 Claude Code 也去读同一份，两家共用一套约定。

把这次对话里我反复强调的写作要求整理进 AGENTS.md。只写以后每次都适用的，不超过十行。

做成 Skill。 AGENTS.md 是每次都要遵守的规矩，Skill 是用到时才加载的一套做法。把练习 2 的流程和 style_table.md 打包成 Skill，下次一句话就能调出来。

把练习 2 的重讲流程和 style_table.md 做成本项目的一个 Skill，名字叫 plain-retell。
做完告诉我它存在哪里，以后怎么调用。

请 Codex 审。 在 Codex 里打开同一个文件夹：

你是期刊编辑。只看 v2.md 和 style_table.md，不看其他稿子。
先只读第一段，判断读者会不会想往下读。再逐段指出还有 AI 味的地方，指到具体句子，说明往哪个方向改。
意见存成 review.md，注明你审的是 v2.md。不要改 v2.md。

回到 Claude，让它按意见再重讲一稿：

读 review.md，按意见把 v2.md 整体重讲一遍，存成 v3.md。不要逐句修补。

最容易出错的地方

逐句修补，越改越长。 每轮改动都在原句上加限定和补充，几轮下来比原稿还长。改不动的时候，让它合上原稿整体重讲。

叮嘱它要严谨。 写作任务里加一句不要夸大、注意准确，结果就是满篇限定。写作只交代读者是谁，最想让读者记住什么。数字对不对，另开一步专门核对。

自己审自己。 同一个模型写完再审，挑出的多是错别字。换一家的 Agent 审，并让意见注明审的是哪一版，稿子改了就重审，旧意见不能挂在新稿上。

AGENTS.md 越写越长。 每出一次问题就往里加一条，几周后几百行，Agent 反而不照做了。只留长期稳定的约定，加新的之前先删重复的。

在 AI 科学家里。 AI 科学家写论文时也分这两步：叙事编辑读懂全文后，照目标刊会的范文另起一稿；再由另一家厂商的 Agent 以编辑的眼光审稿，读完标题和摘要不想往下读，就退回重写。你正在读的这份教程，也是这样改出来的。

换成你自己的材料

找一段你自己写过、不太满意的稿子，再挑一篇你最欣赏的论文当范文。开一个新对话，说一句用 plain-retell 重讲这段稿子，然后让 Codex 审一遍。

要点

  • 改稿靠范文和整体重讲，不靠逐句修补。
  • 写和审交给不同厂商的 Agent，意见对应到具体版本。
  • 反复说的要求写进 AGENTS.md，反复做的流程做成 Skill。

1 Writing with Agents

In an hour you will have a paragraph of your own retold so it reads like the paper you most admire, with no trace of AI. You will also have a writing Skill you can call any time.

Download the Session 1 materials

See the finished product, 5 minutes

Open before.md and after.md from the materials. Both describe the same thing: an agent that pre-screened new papers for a research group for three months. The first is typical AI prose. It opens with background, hedges every sentence, and closes with “not about replacing researchers but about becoming their capable assistant”. The second opens with the result:

In three months, an agent read 4,200 new papers for our group. It recommended 310, and 268 of them were worth a close read.

Not one number changed. Only the telling did. That is what this session is about.

Where the AI flavour comes from, 10 minutes

Most of it comes from three habits. Hedges everywhere: every sentence carries a “to some extent” or “preliminary results indicate” as an escape hatch. Stock frames: “not X but Y”, “notably”, “in conclusion”. And listing instead of choosing, so the reader can’t find the point.

Ask an agent to polish sentence by sentence and all three get worse. Each round adds to the sentence already there, and the draft keeps growing. What works is to give it an exemplar, have it read the draft, then set the draft aside and retell it from scratch around the single most gripping point.

One more thing. Nobody catches their own faults, and models are no different. When the same model writes and reviews, it shares its own taste and can’t see the problems. So in this session Claude writes and Codex reviews.

Exercise 1: one-line polish, 10 minutes

Start with a control. Open the lesson-1 folder in Claude and send:

Read draft.md, make it read better, and save it as v1.md.

Check v1 against style_table.md. You will probably find the words changed and the sentences flow, but it still opens with background and the hedges are still there.

Exercise 2: retell after an exemplar, 15 minutes

The exemplar is a well-written paper. In class we use the ResNet paper, whose abstract says one thing in five sentences. Afterwards, use the paper you admire most.

Download the PDF of arXiv 1512.03385 into the exemplar/ folder.
Read its abstract and introduction, and tell me in three sentences how its opening hooks the reader.
Then read draft.md and tell me the one thing in it most worth remembering.
Don't edit the draft. Build a fresh version around that point, told the way the exemplar tells things, and save it as v2.md.

Put v1 and v2 side by side. v2 should open with the result and be clearly shorter.

Exercise 3: keep the rules, get a second vendor to review, 15 minutes

Write it into AGENTS.md. You have probably said “drop the background” and “stop hedging” several times already. Repeating it in every new conversation gets old, so put it in the project’s AGENTS.md. Codex reads that file every time it starts. The CLAUDE.md in the materials holds one line, @AGENTS.md, which tells Claude Code to read the same file, so both agents share one set of conventions.

Collect the writing requirements I kept repeating in this conversation into AGENTS.md. Only rules that always apply, ten lines at most.

Make it a Skill. AGENTS.md holds rules that always apply. A Skill is a method loaded only when needed. Package the exercise 2 workflow and style_table.md as a Skill, and next time one line brings it back.

Turn the retelling workflow from exercise 2, together with style_table.md, into a Skill for this project called plain-retell.
Tell me where it is saved and how to call it.

Ask Codex to review. Open the same folder in Codex:

You are a journal editor. Look only at v2.md and style_table.md, no other drafts.
First read only the opening paragraph and judge whether a reader would want to go on. Then go paragraph by paragraph and point out what still reads as AI-written, quoting the sentence and saying which way to change it.
Save your comments as review.md and note that you reviewed v2.md. Don't edit v2.md.

Back in Claude, have it retell once more from the comments:

Read review.md and retell v2.md as a whole following the comments. Save it as v3.md. Don't patch sentence by sentence.

Where agents go wrong most

Patching sentence by sentence, the draft keeps growing. Each round adds a hedge or a clarification to the sentence already there, and a few rounds later the draft is longer than the original. When it stops improving, have the agent put the draft aside and retell the whole thing.

Telling it to be rigorous. Add “don’t overclaim” or “be precise” to a writing task and you get hedges everywhere. For writing, say only who the reader is and what you most want them to remember. Checking the numbers is a separate step.

Reviewing its own work. The same model reviewing what it wrote mostly finds typos. Have another vendor’s agent review, and make every review name the version it read. When the draft changes, review again; old comments don’t carry over to a new draft.

AGENTS.md keeps growing. Add a line every time something goes wrong and in a few weeks it is hundreds of lines long, and the agent stops following it. Keep only stable, long-term conventions, and remove duplicates before adding anything new.

Inside the AI Scientist. The AI Scientist writes papers in the same two steps. A narrative editor reads the whole paper and writes a fresh version modelled on an exemplar from the target venue. Then an agent from a different vendor reviews it as an editor would, and if the title and abstract don’t make it want to read on, the draft goes back. The course you are reading was revised the same way.

Now with your own material

Pick a paragraph you wrote and are not happy with, and a paper you admire as the exemplar. Open a new conversation, say “use plain-retell on this paragraph”, then have Codex review the result.

Key points

  • Revise with an exemplar and a full retell, not sentence-by-sentence patches.
  • Give writing and reviewing to agents from different vendors, and tie every review to a specific version.
  • Requirements you repeat go into AGENTS.md; workflows you repeat become Skills.
