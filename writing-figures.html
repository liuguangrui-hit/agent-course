1.3 结果绘图

学习目标

  1. 根据图要回答的比较选择横轴、分组和统计量，并说明舍弃部分数据的依据。
  2. 区分标准差、置信区间与配对差区间的含义，在图注中写明统计量、重复单位和样本量。
  3. 在最终栏宽和成稿中检验图的可读性，并核对图所用数据与正文的指标身份一致。

课后深入专题，约 45 分钟。

设计训练曲线前，应先明确它要回答的问题。仅把所有运行都画出来，并不能回答问题。练习中的关键变化发生在早期峰值与最终结果之间，图应清楚呈现这一变化。

确定比较关系

训练轨迹回答何时开始退步，按噪声比例汇总的图回答方法差距怎样变化。每个问题选择合适的横轴，只保留直接相关的方法和不确定性。

读 data/，为两张图各写一个问题和一句回答。
列出画出的指标、分组和种子数。再说明读者看图时要比较哪些位置。
据此重写 plot_paper.py，保留底层数据与完整运行清单。

图注首句说明读者看到的内容，其后解释统计量和条件。主图取舍之后，完整数据可放入表格或附录，读者仍能查到。

按最终栏宽设计

先从目标模板取得 \columnwidth 或 \textwidth，再设置画布。8 英寸的默认图缩到 3.25 英寸后，原来 10 磅的字只剩约 4 磅。

fig, ax = plt.subplots(figsize=(3.25, 2.3))
plt.rcParams.update({"font.size": 8, "pdf.fonttype": 42})

具体字号按目标刊会要求调整。导出矢量 PDF，编译后按实际阅读尺寸检查最小标注。图在生成阶段就与正文栏宽一致，插入时使用模板约定的尺寸。

均值与不确定性

均值表示典型水平，标准差表示各种子之间的离散程度，置信区间表示均值估计的不确定性。图注应写明使用哪一种，并说明独立重复的单位。

比较两种方法时，各自误差带的重叠程度不能代替配对差值的区间。若两种方法共用种子与数据划分，应先按种子求差，再分析差值。3.3 节将展开这一比较。

样本量较小时可以同时画出散点，让读者看到五个种子各自的结果。曲线需要汇总时，保留均值与误差带，避免把每次运行都画成同等醒目的主线。

方法配色的一致性

同一方法在每张图中使用同一种颜色，由方法名映射。再辅以直接标注或线型，使黑白打印时仍能区分。曲线相距很近时，使用外置图例或错开的标签，不能为了标注清楚而移动数据。

连续量使用有序配色，方法类别使用离散配色。可以从 Okabe 与 Ito 的方案开始，再检查图在色弱模拟下是否仍可区分。

坐标范围与数据筛选

比较柱长时，纵轴通常从零开始；折线图可以聚焦一段变化，但须标明范围。不同子图需要比较高度时，尽量共用纵轴；确需不同范围，应在图注中明确说明。删除一个离群种子会改变结论时，必须有预先定义的处理依据。

绘图阶段发现某个种子异常时，应回到运行记录查找原因。原始数据保留，绘图脚本记录筛选条件，审阅者可以同时生成包含全部种子的版本。

成稿检查

编译本版论文，把每页渲染为图片并逐页看。
检查图内最小字，标签遮挡，图文指向和图注位置。
同时重算每条线的分组均值，确认图脚本用了预定指标。
版面问题改脚本或排版，再生成，不手改图片。

机械核查能发现取错数据列，视觉检查能发现字号过小，两者缺一不可。只看单独导出的图，无法判断它在论文中的实际效果。

练习

针对四成噪声下的最终准确率，分别画方法散点图和带误差条的横向图。再回到噪声比例曲线，说明三种图各自能回答什么问题。为正文选定一种，其余保留在分析记录中。

常见错误与处理方法

为使曲线平滑美观，未加说明地处理数据。 把平滑方法写入脚本和图注，并保留未平滑曲线供核对。

把各种误差都称为误差棒。 在图注中写明统计量、重复单位和样本量。

图与正文描述的对象不同。 核查图的数据筛选条件，再对照正文的指标身份。

延伸阅读：Ten Simple Rules for Better Figures 与 Fundamentals of Data Visualization。

1.3 Plotting results

Learning outcomes

After this section, students should be able to:

  1. Derive the design of a figure from the comparison it must support, including the axes, the groups shown and the representation of uncertainty.
  2. Select and justify a summary statistic and uncertainty measure, stating the unit of independent replication.
  3. Evaluate a figure in the compiled paper at final size, and verify that the plotted quantities match the metric stated in the text.

Extension reading and exercises, about 45 minutes.

Plotting every run does not tell the reader where to look. A figure is designed to make one comparison visible. In the exercise, the key change occurs between the early peak and the final result, and the figure should make that change clear.

Defining the comparison first

The training trajectory answers when the decline begins; the figure aggregated by noise rate answers how the gap between methods changes. Each question determines a suitable horizontal axis, and each figure keeps the directly relevant methods together with their uncertainty.

Read data/ and write one question and a one-sentence answer for each of the two figures.
List the metrics plotted, the groups and the number of seeds. Then say which places the reader has to compare when looking at the figure.
Rewrite plot_paper.py accordingly, keeping the underlying data and the full list of runs.

The first sentence of the caption tells the reader what is shown; the remainder explains the statistics and conditions. Full data omitted from the main figure can be given in a table or appendix, where readers can still find them.

Designing for the final column width

Obtain \columnwidth or \textwidth from the target template before setting the canvas. A default 8-inch figure reduced to 3.25 inches turns 10 pt text into about 4 pt.

fig, ax = plt.subplots(figsize=(3.25, 2.3))
plt.rcParams.update({"font.size": 8, "pdf.fonttype": 42})

The exact font size follows the target venue’s requirements. Export vector PDF, and after compilation check the smallest label at actual reading size. The figure is generated to match the text column width and inserted at the size the template specifies.

Means and uncertainty

The mean gives the typical level, the standard deviation gives variation across seeds, and a confidence interval gives the uncertainty of the mean estimate. The caption states which is used and what the unit of independent replication is.

When two methods are compared, the overlap of their separate error bands cannot substitute for the interval of the paired difference. If both share seeds and data splits, subtract by seed first and then examine the difference. Section 3.3 develops this comparison.

With small samples, individual points can also be plotted so that readers see the results for all five seeds. When curves are aggregated, keep the mean and the error band rather than drawing every run as an equally prominent line.

Consistent method colors

The same method uses the same color in every figure, mapped from the method name. Direct labels or line styles keep the figure readable in black-and-white print. For lines close together, use an external legend or staggered labels; data are never moved to make a label clearer.

Use an ordered palette for continuous magnitudes and a discrete palette for method categories. Okabe and Ito’s scheme is a suitable starting point; check that the figure remains distinguishable in a simulation of color vision deficiency.

Making the scale visible

Bar charts that compare lengths should usually start at zero; line charts may focus on a range of change, but the range must be clearly marked. When panels are compared by height, share the vertical axis where possible; if different ranges are genuinely required, state this in the caption. Removing an outlier seed changes the conclusion and therefore requires a rule defined in advance.

If a seed appears abnormal during plotting, return to the run records to establish the cause. Keep the raw data, have the plotting script record the filter conditions, and allow the reviewer to generate a version that includes all seeds.

Checking the compiled paper

Compile this version of the paper, render each page as an image and look at them page by page.
Check the smallest text inside figures, overlapping labels, references between text and figures, and caption placement.
Also recompute the group mean of each line to confirm the plotting script used the intended metric.
Fix layout problems in the script or the typesetting, then regenerate. Do not edit images by hand.

Mechanical checks detect a wrong column; visual checks detect text that is too small. Both are needed. An attractive exported figure does not show how the figure functions in the paper.

Exercise

For final accuracy at 40% noise, draw a scatter plot by method and a horizontal plot with error bars. Then return to the noise-rate curve and state which question each of the three figures can answer. Choose one for the main text and keep the others in the analysis record.

Common errors and corrections

Processing data without disclosure to make a figure smooth. Write the smoothing into the script and caption, and keep the unsmoothed curve for checking.

Calling every measure of uncertainty an error bar. State the statistic, the unit of replication and the sample size in the caption.

A figure and its text referring to different quantities. Check the figure’s data filter conditions against the metric identity in the text.

Further reading: Ten Simple Rules for Better Figures and Fundamentals of Data Visualization.
