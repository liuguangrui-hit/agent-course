1.3 结果绘图

课后深入，约 45 分钟。

一张训练曲线要回答什么问题？把所有运行都画出来，还不足以回答这个问题。练习里的关键变化发生在早期峰值与最终结果之间，图应当清楚展示这个变化。

先决定比较关系

训练轨迹回答什么时候开始退步，按噪声比例汇总的图回答方法差距怎样变化。每个问题选适合的横轴，保留直接相关的方法和不确定性。

读 data/，为两张图各写一个问题和一句回答。
列出画出的指标、分组和种子数。再说明读者看图时要比较哪些位置。
据此重写 plot_paper.py，保留底层数据与完整运行清单。

图注第一句告诉读者看到了什么，后面解释统计量和条件。主图取舍后的完整数据可以放到表格或附录，读者仍能找到。

用最终栏宽设计

先从目标模板取得 \columnwidth 或 \textwidth，再设置画布。用 8 英寸的默认图缩到 3.25 英寸，原来 10 磅的字只剩约 4 磅。

fig, ax = plt.subplots(figsize=(3.25, 2.3))
plt.rcParams.update({"font.size": 8, "pdf.fonttype": 42})

具体字号按目标刊会要求调整。导出矢量 PDF，编译后按实际阅读大小看最小标注。图在生成阶段与正文栏宽一致，插入时再用模板约定的尺寸。

均值与不确定性

均值给典型水平，标准差给这些种子之间的分散程度，置信区间给均值估计的不确定性。图注写明用哪一种，并说明独立重复的单位。

比较两个方法时，方法各自的误差带重叠多少，不能直接代替配对差值的区间。若两边共用种子与数据划分，应先按种子相减，再看差值。第 3.3 节会把这个比较展开。

小样本可以同时画散点，让读者看到五个种子各自的结果。曲线需要汇总时，保留均值与误差带，避免把每次运行都画成同等醒目的主线。

统一方法配色

同一个方法在每张图里使用同一种颜色，由方法名映射。再配直接标注或线型，让黑白打印仍可区分。接近的线用外置图例或错开的标签，不能为了标注清楚而移动数据。

连续大小使用有顺序的配色，方法类别使用离散配色。可以从 Okabe 与 Ito 的方案开始，再检查自己的图在色弱模拟中是否仍能区分。

坐标范围与数据筛选

比较柱长通常从零开始，折线图可以聚焦一段变化，但要把范围标清。不同子图要比较高度时，尽量共用纵轴；确需不同范围，在图注明确指出。删掉一个离群种子会改变结论，必须有预先定义的处理依据。

绘图阶段若发现某个种子异常，回到运行记录查原因。原始数据保留，图脚本记录筛选条件，审阅者可以同时生成含全部种子的版本。

在成稿中检查

编译本版论文，把每页渲染为图片并逐页看。
检查图内最小字，标签遮挡，图文指向和图注位置。
同时重算每条线的分组均值，确认图脚本用了预定指标。
版面问题改脚本或排版，再生成，不手改图片。

机械核查发现拿错列，视觉检查发现字太小，两者都需要。只看漂亮的导出图，找不到它在论文中的实际效果。

练习

对四成噪声下的最终准确率，分别画方法散点图和带误差条的横向图。再回到噪声比例曲线，说出三种图各能回答什么。为主文选一种，其余保留到分析记录。

常见错误与处理方法

为了平滑好看，悄悄处理数据。 平滑写进脚本和图注，保留未平滑曲线供核对。

把每种误差都叫误差棒。 在图注写出统计量、重复单位和样本量。

图和正文说的对象不同。 核查图的数据筛选条件，再对照正文的指标身份。

1.3 Plotting results

After-class deep dive, about 45 minutes.

Plotting every run does not tell the reader where to look. In the exercise, the key change happens between the early peak and the final result, and the figure should make that change clear.

Decide the comparison first

The training trajectory answers when the decline begins; the figure aggregated by noise rate answers how the gap between methods changes. Choose a suitable horizontal axis for each question, and keep the directly relevant methods and their uncertainty.

Read data/ and write one question and a one-sentence answer for each of the two figures.
List the metrics plotted, the groups and the number of seeds. Then say which places the reader has to compare when looking at the figure.
Rewrite plot_paper.py accordingly, keeping the underlying data and the full list of runs.

The first sentence of the caption tells the reader what they see; the rest explains the statistics and conditions. The full data left out of the main figure can go into a table or appendix, where readers can still find them.

Design for the final column width

First get \columnwidth or \textwidth from the target template, then set the canvas. A default 8-inch figure shrunk to 3.25 inches turns 10 pt text into about 4 pt.

fig, ax = plt.subplots(figsize=(3.25, 2.3))
plt.rcParams.update({"font.size": 8, "pdf.fonttype": 42})

Adjust the exact font size to the target venue’s requirements. Export vector PDF, and after compiling check the smallest label at actual reading size. The figure matches the text column width when it is generated, and is inserted at the size the template specifies.

Means and uncertainty

The mean gives the typical level, the standard deviation gives variation across seeds, and a confidence interval gives the uncertainty of the mean estimate. The caption states which one is used and what the unit of independent replication is.

When comparing two methods, how much their separate error bands overlap cannot stand in for the interval of the paired difference. If both share seeds and data splits, subtract by seed first, then look at the difference. Section 3.3 develops this comparison.

With small samples you can also plot the points, so readers see the individual results for all five seeds. When curves need aggregating, keep the mean and the error band, and avoid drawing every run as an equally prominent main line.

Use consistent method colors

The same method uses the same color in every figure, mapped from the method name. Add direct labels or line styles so it still reads in black-and-white print. For lines close together, use an external legend or staggered labels; never move data to make a label clearer.

Use an ordered palette for continuous magnitudes and a discrete palette for method categories. You can start from Okabe and Ito’s scheme, then check that your figure remains distinguishable in a simulation of color vision deficiency.

Let the reader see the scale

Bar charts used to compare lengths should usually start at zero; line charts can focus on a range of change, but the range must be clearly marked. When panels are compared by height, share the vertical axis where possible; if different ranges are truly needed, say so explicitly in the caption. Removing an outlier seed changes the conclusion, so it needs a rule defined in advance.

If a seed looks abnormal during plotting, go back to the run records to find the cause. Keep the raw data, have the plotting script record the filter conditions, and let the reviewer generate a version that includes all seeds.

Check in the compiled paper

Compile this version of the paper, render each page as an image and look at them page by page.
Check the smallest text inside figures, overlapping labels, references between text and figures, and caption placement.
Also recompute the group mean of each line to confirm the plotting script used the intended metric.
Fix layout problems in the script or the typesetting, then regenerate. Do not edit images by hand.

Mechanical checks find the wrong column; visual checks find text that is too small. You need both. Looking only at a nice exported figure does not show how it actually works in the paper.

Exercise

For final accuracy at 40% noise, draw a scatter plot by method and a horizontal plot with error bars. Then go back to the noise-rate curve and say what each of the three figures can answer. Choose one for the main text and keep the others in the analysis record.

Common mistakes and how to fix them

Quietly processing data to make it smooth and pretty. Write the smoothing into the script and caption, and keep the unsmoothed curve for checking.

Calling every measure of uncertainty an error bar. State the statistic, the unit of replication and the sample size in the caption.

The figure and the text are about different things. Check the figure’s data filter conditions, then compare them with the metric identity in the text.
