6 编排理论

本节课目标

完成本节课堂训练及课后练习后，学生应能：

  1. 形式化定义原点、外部经验、策略、回报与更新器，其中原点指版本固定的完整 Agent，并指出研究者能够控制的对象。
  2. 区分单步与序贯两类学习问题，以及内环经验更新与外环规则更新两个层级的学习对象。
  3. 设计三组比较与反馈打乱对照，分别检验总效应、内容效应和收益对正确反馈的依赖。
  4. 分析经验收益成立的泛化条件，以及跨原点迁移、原点漂移和资源成本对结论的影响。

课堂用合成演算数据练习分析流程；真实的学习效果须按冻结协议在新任务上测量，在课后完成。

选修课。课前完成准备，课堂 60 分钟，课后完成复习、独立实践与迁移评价，另可选做深入专题。

课前准备 · 课堂教学 · 课后复习与扩展

本节讨论模型权重固定条件下的 Agent 学习。第 4 课形成的经验榜可作为外部经验，影响 Agent 在新任务中的行为；其效果可能随 Agent 或版本改变。分析重点是可学习对象、更新机制及学习收益的识别。

Claude Code 和 Codex 这类完整 Agent 由厂商提供，包含模型、工具接口与执行循环。研究者能够控制的对象包括外部经验、任务选择和依据结果更新经验的规则。

课堂教学

以一条冒烟测试经验为例，10 分钟

先确认材料可以读取，把课前带来的经验写在白板上，再共同定义学习过程。

回到第 4 课的那条经验：实验输出格式改变后，短运行结束时检查每一列和行数，再提交正式任务。

设同一个 Agent 接到一项新实验。它先读取当前经验榜，写出测试程序，运行器检查结果文件。若漏掉必需的列，回报记为零；结构检查全部通过，回报记为一。更新器读取这次失败，把经验改得更具体，例如要求同时核对列名与每列的有限值。

下一项任务更换了数据和输出格式，Agent 再读取修改后的经验榜。需要测量的是：这份经验能否使它在新任务上减少同类错误。执行任务的 Agent 保持不变，行为依据和更新规则保存在它之外。

学习过程的形式化，5 分钟

把固定版本的闭源 Agent 记作 𝒜v\mathcal A_v，上述经验榜记作 BB。新实验的材料为 xx，Agent 给出的测试程序为 yy：

y∼𝒜v(⋅∣x,B).y\sim\mathcal A_v(\cdot\mid x,B).

运行器给出回报 rr，更新器 UϕU_\phi 把经验榜改为下一版：

Bt+1=Uϕ(Bt,xt,yt,rt).B_{t+1}=U_\phi(B_t,x_t,y_t,r_t).

不同的 BB 使同一原点形成不同的策略。经验独立保存，因此可以交给另一家 Agent 再次测试。原点在两处充当参照：它是系统不作修改的执行单元，它在无经验条件下的表现又是测量学习增量的零点。

内环与外环，5 分钟

内环依据回报修改经验，目标是减少以后任务中的漏检。此时策略参数是一份离散文本，更新器在文本空间中搜索。这一问题可以表述为强化学习，检验的重点是回报怎样影响更新。

外环修改的是合并与淘汰经验的规则。例如，原先每次失败都新增一条，现在改为先合并相近条目，再用验证任务决定保留与否。这一层改变的是学习算法本身，对应自进化。评价器继续使用同一套检查和最终确认任务，改进才有共同的参照。

在上例中，每项格式检查只给出一次回报，下一项任务由外部给定，最小结构接近情境老虎机。在实际研究中，实验的选择会改变已知证据，后续动作也随之改变，问题便进入序贯决策与延迟回报。深入专题将分别写出两种目标。

三组比较与效应分解，10 分钟

每个未见任务分别在目标经验、匹配安慰剂和无经验三组条件下运行。三组的平均回报记为 J(B)J(B)、J(P)J(P) 与 J(⌀)J(\varnothing)：

J(B)−J(⌀)=[J(B)−J(P)]+[J(P)−J(⌀)].J(B)-J(\varnothing) =[J(B)-J(P)]+[J(P)-J(\varnothing)].

总效应回答带有这张经验榜比原点自身高出多少。右侧第一项比较内容，第二项反映匹配安慰剂带来的变化。这一等式恒成立；第一项能否解释为学到的知识，取决于安慰剂是否配平了格式、篇幅和其他非特异作用。

还需检验学习信号。另学一张经验榜，训练时打乱任务与回报的对应关系，其余预算相同。两张榜都在正常的未见任务上评估，才能判断改进是否依赖正确的反馈。

选一个科研行为，例如根据实验设置提出可区分的假设。

本节小结

可修改对象、更新器和评估器现在都有明确身份。这一框架既能提出一种学习方法，也能说明它在何种结果下会被否定。用量账本最终衡量取得这些收益所消耗的资源。

正反例辨析，20 分钟

先看一组假设数字：目标经验 0.64，匹配安慰剂 0.62，无经验 0.50。甲把全部 0.14 的增量称为学到的知识。乙同时报告内容差 0.02 和安慰剂差 0.12，并检查配平、区间和正确反馈的作用。判断两种解读各需要哪些证据。再打开课堂上 analyze_experience.py 的输出，用同一分解解释 design 行为在 origin-v2 下的结果，说明目标经验低于安慰剂时，甲的解释哪里不成立。若更换原点后三组都提高，写出怎样比较旧经验是否仍有增量。

自行分解三组后，再查看参考思路

0.14 是总效应，恒等分解给出 0.02 与 0.12。要把内容差解释为知识收益，还须检查安慰剂是否配平，并估计不确定性与对反馈的依赖。课堂演算中，design 行为在 origin-v2 下的目标经验低于安慰剂，说明总效应不能代替内容差。跨原点比较时，分别以各自的无经验组和安慰剂组作参照，不能只比较目标经验的绝对分数。

6 Orchestration theory

How a system can learn while the model weights remain fixed

Learning outcomes

After completing this session and its review and extension work, students should be able to:

  1. Formally define the fixed agent (the origin), the external experience, the induced policy, the reward and the updater of an agent-based learning system.
  2. Distinguish single-step from sequential learning problems, and the inner loop that updates experience from the outer loop that changes the learning rule.
  3. Design tests that separate the total effect of experience from the effect of its content and from its dependence on correct feedback.
  4. Analyze the conditions under which a learning gain generalizes, including transfer across origins, origin drift and resource cost.

The outcomes are assessed at three levels. In class, students formalize one research behavior and analyze a synthetic three-group dataset; the synthetic data serve only for practicing the calculation and carry no evidence about real agents. After class, students design a frozen protocol, and the real learning effect is measured on new tasks run under that protocol. The extension paths develop the derivations on policy and credit assignment, effect identification, transfer and cost.

Elective. Preparation before class, a 60-minute class session, then required review, independent work and transfer assessment, with optional further study.

Preparation · Class session · Review and extension

This session examines agent learning with fixed model weights. The playbook developed in Session 4 provides external experience that may change an agent’s behavior on new tasks; its effect may vary across agents or versions. The analysis focuses on the object of learning, the update mechanism and the identification of learning gains.

Complete agents such as Claude Code and Codex are supplied by vendors and comprise the model, the tool interfaces and the execution loop. Researchers can control the external experience, task selection and the rules for updating experience from results. The fixed complete agent is called the origin.

Download the Lesson 6 materials

The exercise package contains three groups of scores, a learning protocol and a usage ledger. The scores and the ledger are synthetic worked-example data for practicing the analysis; real effects are measured by the students themselves, calling their own agent under the frozen protocol.

Class session

A playbook entry from a smoke test, 10 minutes

Confirm that the materials can be read and put the entry brought to class on the whiteboard; the learning process is then defined jointly.

Return to the entry from Session 4: when the format of experiment output changes, check every column and the number of rows after a short run, then submit the real job.

The same agent is given a new experiment. It first reads the current playbook and writes a test program, and the runner checks the result file. If a required column is missing, the reward is zero; if the structure check passes entirely, the reward is one. The updater reads this failure and makes the entry more specific, for example by requiring both the column names and the finite values in each column to be checked.

The next task changes the data and the output format, and the agent reads the revised playbook again. The quantity of interest is whether this entry reduces errors of the same kind on new tasks. The agent doing the work remains fixed; the basis for its behavior and the update rule are kept outside it.

Formalizing the learning process, 5 minutes

Write the fixed-version closed-source agent as 𝒜v\mathcal A_v and the playbook as BB. The material of the new experiment is xx, and the test program the agent produces is yy:

y∼𝒜v(⋅∣x,B).y\sim\mathcal A_v(\cdot\mid x,B).

The runner returns a reward rr, and the updater UϕU_\phi changes the playbook into the next version:

Bt+1=Uϕ(Bt,xt,yt,rt).B_{t+1}=U_\phi(B_t,x_t,y_t,r_t).

Different choices of BB induce different policies from the same origin. Because experience is kept separately, it can be given to another vendor’s agent and tested again. The origin serves as the reference in two respects: it is the execution unit the system does not modify, and its performance without experience is the baseline for measuring learning gains.

The inner and outer loops, 5 minutes

The inner loop changes the entry according to the reward, with the aim of reducing misses on later tasks. The policy parameter is a discrete piece of text, and the updater searches in text space. The problem can be stated as reinforcement learning, and how the reward affects the update is the focus of testing.

The outer loop changes the rules for merging and retiring entries. For example, instead of adding an entry for every failure, similar entries are first merged and validation tasks then decide what is kept. This layer changes the learning algorithm, which is what self-evolution means in this course. The evaluator continues to use the same checks and final confirmation tasks, so that improvements have a common reference.

In the example above, each format check gave a single reward and the next task was supplied externally, so the minimal structure is close to a contextual bandit. In real research, choosing an experiment changes the available evidence, and later actions change accordingly; this introduces sequential decision-making and delayed reward. The extension pages state the two objectives separately.

Decomposing the effects with three groups, 10 minutes

Each unseen task is run in three groups: target playbook, matched placebo and no playbook. Writing their average rewards as J(B)J(B), J(P)J(P) and J(⌀)J(\varnothing):

J(B)−J(⌀)=[J(B)−J(P)]+[J(P)−J(⌀)].J(B)-J(\varnothing) =[J(B)-J(P)]+[J(P)-J(\varnothing)].

The total effect measures how much higher the origin scores with this playbook than without it. The first term compares content; the second shows the change produced by the matched placebo. The identity always holds; whether the first term can be interpreted as learned knowledge depends on whether the placebo balances format, length and other non-specific effects.

The learning signal also requires a test. A second playbook is trained with shuffled task–reward pairings during training, keeping the rest of the budget unchanged. Only when both playbooks are evaluated on normal unseen tasks can one judge whether the improvement depends on correct feedback.

Common errors and summary, 5 minutes

Common errors and corrections

Assuming the gain must increase because an update formula has been written. State the updater’s basis for selection and compare on unseen tasks; convergence requires further assumptions.

Taking a usage claim as an entry’s contribution. Usage claims are used to propose candidates; contribution is tested with ablations or randomized interventions.

Merging scores of different versions of the same playbook into one curve. Start a new statistical segment for each new version, and keep bridging tasks to measure drift.

Method summary

The learnable object, the updater and the evaluator are now explicitly defined. The system can propose a way of learning and can also state how that proposal could be refuted. The final ledger exercise measures the resources required to obtain these gains.

Unaided review, 15 minutes

Without consulting the formulas, use your own playbook entry to explain how input becomes output and how reward drives the update. Then draw the fixed origin and the changeable experience, connect the updater and the evaluator to the diagram, and indicate which change belongs to the inner loop and which changes the learning rule. Analysis of contrasting examples, 20 minutes

Consider a set of hypothetical numbers: target playbook 0.64, matched placebo 0.62, no playbook 0.50. Interpretation A attributes the whole gain of 0.14 to learned knowledge. Interpretation B reports both the content difference of 0.02 and the placebo difference of 0.12, then checks balancing, intervals and the role of correct feedback. Judge which evidence each interpretation requires. Then open the output of analyze_experience.py from class, use the same decomposition to explain the result for the behavior labeled design under origin-v2, and state where A’s interpretation fails when the target playbook scores below the placebo. If all three groups improve after the origin changes, state how one would determine whether the old playbook still adds anything.

Decompose the three groups before reading the commentary

0.14 is the total effect, and the identity divides it into 0.02 and 0.12. Interpreting the content difference as a knowledge gain still requires checking that the placebo is balanced and estimating the uncertainty and the dependence on feedback. In the class worked example, the target playbook for design under origin-v2 scores below the placebo, which shows that the total effect cannot stand in for the content difference. Across origins, each origin’s own no-playbook and placebo groups serve as references, rather than the absolute scores of the target playbook alone.

Assessment

Attainment of the outcomes is judged from the student’s formal definitions and the reasoning attached to them. Students should be able to state, for their chosen behavior, what the origin is, what experience may change, how reward is computed and what the updater does; classify the task as single-step or sequential and justify the classification; explain which comparison identifies the total effect, the content difference and the dependence on correct feedback, and what each requires; and state why the synthetic class data support only the calculation, while a real learning effect must be established on new tasks under the frozen protocol. Transfer is assessed by applying the same definitions to a different research behavior or origin and identifying which assumption the new setting puts at risk.

Independent assessment requires the planned evaluation on new tasks under the frozen protocol, with effect estimates, uncertainty and limitations reported. The transfer task must explain which results need to be remeasured when the research behavior or origin changes, and how usage affects the deployment decision.
