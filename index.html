用 Agent 做科研

从一篇稿子到一位 AI 科学家

面向研究生和带研究生的老师。四堂实践课，外加两堂选修。每堂课堂核心一小时，下课时手里有一个当堂做出来、能接着用的东西；课后还有几节深入内容，按需自学，把这一课的本事练扎实。

Agent 已经能读文件和跑代码，也能查资料和写网页。真正拉开差距的是会不会组织它干活：给它什么材料，让谁写谁审，什么时候放手让它自己跑，什么时候必须停下来看一眼。这门课练的就是这件事。

课程有两条线。明线是科研的四步：写作，探索，实验，自动化。暗线是 Agent 的工具：从第 1 课起，每堂课一开始先让 Agent 自己装上这一课要用的几样工具，你在一旁听课；装好的软件一直留在电脑上，用法记在项目的 AGENTS.md 里，下一课开头由 Agent 抄进新的文件夹接着用。写作要的工具最少，所以放在最前面；之后添浏览器和知识库，再添服务器和后台任务，最后是定时任务和结果网页。到第 4 课，这些工具连成一个能自己转起来的科研工作台。全部工具列在工具箱。

每堂课都有一个当堂能看见的目标，几节课后深入，一份可下载的练习材料，一段 Agent 最容易出错的地方和对应的办法。最后一部分最值钱，它们来自每天和 Agent 一起干活踩过的坑，很少写在官方文档里。

Research with Agents

From one draft to an AI scientist

For graduate students and the people who supervise them. Four hands-on sessions and two electives. Each has a one-hour core class, and you leave with something you built in the room and can keep using; self-study sections after each class take the skill further, at your own pace.

Agents can already read files and run code, search the literature and build web pages. What separates people now is whether they can organise that work: what material to hand over, who writes and who reviews, when to let the agent run on its own, and when to stop and look. That is what this course practises.

The course has two threads. The visible one follows four research steps: writing, exploration, experiments and automation. The hidden thread is the agent’s tools. From Session 1, start each class by having the agent install the few tools it needs while you listen. The software stays on your computer. Its use goes into the project’s AGENTS.md, which the agent copies into the next session’s folder at the start. Writing needs the fewest tools, so it comes first. Then you add a browser and knowledge base, servers and background jobs, and finally scheduled tasks and results pages. By Session 4 these tools form a research workbench that runs on its own. All tools are listed in the Toolbox.

5 Elective: Orchestration Safety A permission table for your workbench and two automatic checks Permission rules, sandbox, Hooks, secret management
6 Elective: Orchestration Theory A usage ledger and an orchestration decision you can compute Usage ledger

Every session has a goal you can see by the end of the hour, several self-study sections, a downloadable case, and a section on where agents go wrong most and what to do about it. That last part is the most valuable. It comes from working with agents every day, and little of it is in the official docs.

Before the first session, spend half an hour on Setup. The schedule and learning outcomes are in the Syllabus.
