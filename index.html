用 Agent 做科研

从一篇稿子到一位 AI 科学家

四堂实践课，外加两堂选修。每堂一小时左右，下课时手里有一个当堂做出来、能接着用的东西。

Agent 已经能读文件和跑代码，也能查资料和写网页。真正拉开差距的是会不会组织它干活：给它什么材料，让谁写谁审，什么时候放手让它自己跑，什么时候必须停下来看一眼。这门课练的就是这件事。

课程从写作开始，因为写作要的工具最少。之后每堂课添几样新工具，先是浏览器和知识库，再是服务器和定时任务。到第四堂，前面做出的东西连成一个能自己转起来的科研循环。

课 下课时你有 新添的工具
0 课前准备 一个能和 Agent 对话的项目文件夹 Claude Code，Codex
1 Agent 写作 一稿没有 AI 味的稿子，一个随时能调用的写作 Skill AGENTS.md，Skill，跨厂商审稿
2 Agent 探索 一个方向的论文知识库，三个能检验的问题 Ego 浏览器，Obsidian，Sub-agent
3 Agent 实验 一次能重跑的实验，一张结果图 Git 与 GitHub，SSH 服务器，后台任务
4 Agent 自动化与自进化 一个夜里自己跑的研究循环 定时唤醒，无人值守调用，经验榜，GitHub Pages
5 选修 编排安全 你的工作台的权限表 权限模式，沙箱
6 选修 编排理论 一个算得出来的编排决策

每堂课都有一个当堂能看见的目标，一份可下载的练习材料，一段 Agent 最容易出错的地方和对应的办法。最后一部分最值钱，它们来自每天和 Agent 一起干活踩过的坑，很少写在官方文档里。

开始之前，先花二十分钟做完课前准备。课程安排和目标见课程大纲。

Research with Agents

From one draft to an AI scientist

Four hands-on sessions and two electives. Each runs about an hour, and you leave with something you built in the room and can keep using.

Agents can already read files and run code, search the literature and build web pages. What separates people now is whether they can organise that work: what material to hand over, who writes and who reviews, when to let the agent run on its own, and when to stop and look. That is what this course practises.

We start with writing, because writing needs the fewest tools. Each session then adds a few: first a browser and a knowledge base, then servers and scheduled jobs. By session four, what you built earlier joins into a research loop that runs by itself.

Session You leave with Tools added
0 Setup A project folder you can talk to an agent in Claude Code, Codex
1 Writing with Agents A draft with no AI flavour, and a writing Skill you can call any time AGENTS.md, Skills, cross-vendor review
2 Exploring with Agents A knowledge base for one research direction, and three testable questions Ego browser, Obsidian, sub-agents
3 Experimenting with Agents An experiment anyone can rerun, and one result figure Git and GitHub, SSH servers, background jobs
4 Automation and Self-Evolution A research loop that runs overnight Scheduled wake-ups, headless runs, playbooks, GitHub Pages
5 Elective: Safety A permission map for your workbench Permission modes, sandbox
6 Elective: Theory An orchestration decision you can compute

Every session has a goal you can see by the end of the hour, a downloadable case, and a section on where agents go wrong most and what to do about it. That last part is the most valuable. It comes from working with agents every day, and little of it is in the official docs.

Before the first session, spend twenty minutes on Setup. The schedule and learning outcomes are in the Syllabus.
